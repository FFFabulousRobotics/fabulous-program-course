# W2.4 FTC 年度交友大会测试数据

共 10 组标准输入和标准输出，每组 10 分。`01`–`03` 同时作为公开样例，与原题的三段样例解释对应；其余数据仅在服务端评测中使用。判断以 `testW2.md` 为准，输出末尾空白可忽略，其他字符严格匹配。

| 测试点 | 覆盖内容 |
| --- | --- |
| 01 | 前两人失败，第三位 D 属性成功 |
| 02 | 身高或性别条件不满足，全部失败 |
| 03 | 前三人失败，第四位成功 |
| 04 | A 不限制性别；等高失败，矮 1 且魅力高 1 成功 |
| 05 | B 只接受同性 |
| 06 | C 只接受异性 |
| 07 | 身高等于/大于 165、魅力等于/小于 90 均失败 |
| 08 | n=1；D 不受身高、魅力及性别条件限制 |
| 09 | n=9；前八人失败，最后一人成功 |
| 10 | 多位符合条件时只输出第一位；A 同性成功 |

`testW2.java` 和 `reference.java` 均使用简化输出：成功时第一行输出 `宣布无人罪`，第二行只输出第一位符合条件的旅行者姓名，不输出其他属性；失败时仍输出 `罪人舞步旋`。题面、公开样例与全部测试点已同步。参考实现与测试数据不放入 public 目录，也不发送给成员浏览器。
