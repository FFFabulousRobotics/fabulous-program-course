# FTC 年度交友大会

## 题目背景

在遥远的 FFF 星球上，生活着一群无忧无虑的盐汽水。  
每年，这里都会举办一场盛大的年度盛会——FTC（FFF Total Communication）。  
盐汽水们可以在 FTC 上结识各种伙伴。

但 FFF 星球有一条严苛到离谱的 **交友规则**：

如果一只盐汽水连续三年没有结识新伙伴，  
就会被押到海边，接触 **原始胎海之水**，然后溶解，彻底消失。

FFF 星球的盐汽水分为两个性别：**0** 和 **1**。  
每只盐汽水还带有一种属性：**A、B、C、D**。

结交伙伴的规则如下：

- **A 属性**：可以和任何人交友。
- **B 属性**：只跟自己性别相同的盐汽水交友。
- **C 属性**：只跟自己性别不同的盐汽水交友。
- **D 属性**：最特殊。
  - 如果遇到属性相同的人，也就是对方也是 D，直接交友成功。
  - 否则，必须同时满足：
    1. 性别满足 A/B/C 的条件；
    2. 对方身高矮于自己；
    3. 对方魅力值高于自己。

主角是交友大会的**主办人**，是一只三百年一遇的 **D 型 0 性盐汽水**。  
他的身高足足有 **165cm**，而且因为盐汽水星球的“身高锁定诅咒”，这个数字永远不会变化。  
他的魅力值高达 **90**。

可是，主办人已经连续两年交友失败了。  
今年是第三年，也是最后一年。  
如果再失败，他就会接触原始胎海之水，溶解于 FFF 星球的泡沫之海。

今年，FTC 来了一批异乡旅行者。  
这是主办人唯一的机会了……

---

## 题目描述

主办人是一只 **D 型 0 性盐汽水**，固定信息如下：

- 性别：0
- 属性：D
- 身高：165
- 魅力：90

今年 FTC 来了 `n` 位异乡旅行者。  
主办人会按照输入顺序，依次尝试与每一位旅行者结交伙伴，直到交友成功或所有旅行者都尝试完毕。

一旦交友成功，立刻停止尝试；如果所有旅行者都无法交友成功，则主办人失败，接触原始胎海之水溶解。

旅行者信息包括：姓名、性别、属性、身高、魅力。

主办人与旅行者交友时，规则如下：

1. 如果旅行者属性为 **D**，则直接交友成功。
2. 否则，根据旅行者属性判断性别条件：
   - 旅行者属性为 **A**：性别条件直接满足。
   - 旅行者属性为 **B**：旅行者性别必须为 **0**。
   - 旅行者属性为 **C**：旅行者性别必须为 **1**。
3. 同时，旅行者还必须满足：
   - 身高 **小于 165**；
   - 魅力 **大于 90**。

只有以上条件全部满足，主办人才能与对方交友成功。

如果成功，第一行输出 `宣布无人罪`，第二行只输出第一个交友成功的旅行者的姓名 `name`。  
如果失败，输出 `罪人舞步旋`。

---

## 输入格式

第一行一个整数 `n`，表示旅行者数量，满足 `1 ≤ n < 10`。

接下来 `n` 行，每行表示一个旅行者的信息，格式为：

```text
姓名 性别 属性 身高 魅力
```

其中：

- 姓名：不含空格的字符串；
- 性别：`0` 或 `1`；
- 属性：`A`、`B`、`C`、`D` 之一；
- 身高、魅力：正整数。

---

## 输出格式

如果主办人成功交友：

- 第一行输出：`宣布无人罪`
- 第二行只输出第一个交友成功的旅行者的姓名 `name`。

如果主办人失败：

- 第一行输出：`罪人舞步旋`

## 新手提示：输入与数组

你们已经学过类、构造方法、`if-else`、`switch`、`for`、`while`，只差 **输入** 和 **数组**。  
下面只讲这两件事，不写完整答案。

### 一、输入：Scanner

Java 里读入数据，需要先导入 `Scanner`：

```java
import java.util.Scanner;
```

然后在 `main` 方法里创建它：

```java
Scanner sc = new Scanner(System.in);
```

之后就可以用 `sc` 读数据：

```java
int n = sc.nextInt();          // 读一个整数
String s = sc.next();          // 读一个不含空格的字符串
char c = sc.next().charAt(0);  // 先读字符串，再取第 0 个字符
```

对应本题的输入：

```text
3
提瓦特路人甲 1 A 170 80
```

可以这样读：

```java
int n = sc.nextInt();            // 读 3

String name = sc.next();         // 读 "提瓦特路人甲"
int gender = sc.nextInt();       // 读 1
char type = sc.next().charAt(0); // 读 "A"，再取字符 'A'
int height = sc.nextInt();       // 读 170
int charm = sc.nextInt();        // 读 80
```

注意：`sc.next()` 遇到空格或换行就会停下，所以姓名里不能有空格。

---

### 二、数组：一次存很多个对象

题目里有 `n` 个旅行者，如果每个都写一个变量：

```java
Traveler t1 = new Traveler(...);
Traveler t2 = new Traveler(...);
Traveler t3 = new Traveler(...);
```

`n` 一变大就写不完了。  
这时就用 **数组**。

数组就像一排带编号的格子，每个格子可以放一个同类型的对象：

```java
Traveler[] travelers = new Traveler[n];
```

这句话的意思是：

- 创建一个长度为 `n` 的数组；
- 数组里每个格子可以放一个 `Traveler` 对象；
- 下标从 `0` 开始，分别是 `travelers[0]`、`travelers[1]`、……、`travelers[n - 1]`。

刚创建时，每个格子里都是 `null`，表示“还没有放对象”。  
需要自己 `new` 出来再放进去：

```java
travelers[0] = new Traveler("提瓦特路人甲", 1, 'A', 170, 80);
```

---

### 三、把输入和数组结合起来

用一个 `for` 循环，一边读入，一边存进数组：

```java
Traveler[] travelers = new Traveler[n];

for (int i = 0; i < n; i++) {
    String name = sc.next();
    int gender = sc.nextInt();
    char type = sc.next().charAt(0);
    int height = sc.nextInt();
    int charm = sc.nextInt();

    travelers[i] = new Traveler(name, gender, type, height, charm);
}
```

循环结束后，`travelers[0]` 到 `travelers[n - 1]` 就都存好了旅行者信息。  
这段代码只负责 **输入和存数组**，不负责判断主办人能不能交友成功。

---

### 四、按顺序遍历数组

再用一个 `for` 循环，从 `0` 到 `n - 1` 依次取出每一位旅行者：

```java
for (int i = 0; i < n; i++) {
    Traveler t = travelers[i];

    // 这里写你自己的交友判断
}
```

`t` 就是当前这一位旅行者。  
你可以用已经学过的 `if-else`、`switch` 等语法，自己决定主办人能不能和 `t` 交友成功。

---

### 五、注意点

- 数组下标从 `0` 开始，最后一个下标是 `n - 1`。
- `sc.next()` 读字符串，遇到空格或换行停止。
- 属性只有一个字符，所以用 `sc.next().charAt(0)` 读。
- 交友失败时输出：

```java
System.out.println("罪人舞步旋");
```

- 交友成功时，第一行输出 `宣布无人罪`，第二行只输出朋友的姓名：

```java
System.out.println("宣布无人罪");
System.out.println(friend.name);
```

这里只是告诉你输出格式，不涉及判断逻辑。
