# 1. 类、对象、方法

上节课讲了，class是类，一个代码里可以有多个class，但只有1个public class.

- 类:可以理解为一个概念或者图纸。（可以参考英语中audience, fish这类单词）

- 对象:有状态、有行为的东西。狗是对象——状态是名字 / 品种 / 颜色,行为是叫 / 摇尾巴;

- 方法:可以理解为一个概念包含的行为。

```java
class Arm {               // 定义了一个概念，叫做机械臂
    double grabPosition = 0.4;   // 状态:夹爪当前位置(字段)

    public void grab() {         // 定义一个方法：行为:夹紧
        grabPosition = 0.92;
    }
    public void open() {         // 行为:张开
        grabPosition = 0.4;
    }
    public void show() {         // 行为:报告状态
        System.out.println("夹爪 = " + grabPosition);
    }
}
public class Main {              // 没错，这坨代码的名字叫Main而非Arm
    public static void main(String[] args) {
        Arm arm = new Arm();     // 对象arm是一个机械臂，拥有机械臂的所有状态，本代码中即夹爪的位置是0.4
        arm.show();              // 调用概念里的方法
        arm.grab();              //状态是所有属于这个类的对象都具备的，而方法是需要主动调用的（身上有什么/能做什么）
        arm.show();
    }
}                                //此代码中，类arm起到的作用就是将对象的夹爪位置调成0.4
```
