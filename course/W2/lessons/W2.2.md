# 2. 构造方法

- Arm arm = new Arm() —— 三步:声明(arm)→ 实例化(new)→ 初始化(调构造方法)。

再次提醒:源文件名必须和 public 类名一致(Arm.java),一个文件只能有一个 public 类。

```java
public class Arm {
    double grabPosition;
    String owner;                        // 机械臂这一类拥有主人

    public Arm(String who) {             // 构造方法:与类同名、无返回值
        owner = who;
        grabPosition = 0.4;
        System.out.println(who + " 的机械臂造好了");
    }

    public void grab() { grabPosition = 0.92; }
    public void show() {
        System.out.println(owner + " 的夹爪 = " + grabPosition);
    }
}
```

```java
Arm a1 = new Arm("社员甲");
Arm a2 = new Arm("社员乙");   // 显然，同一类可有多个对象
a1.grab();
a1.show();
```

- 构造方法:与类同名、没有返回值;new 的时候自动执行——可理解为初始化;

- 不写构造方法,Java 会送你一个空的默认构造;

- 构造方法不能有任何返回类型声明，会被当作普通方法处理;
