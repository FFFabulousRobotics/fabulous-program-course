# 3. 关键字this & new

首先引入两个概念：成员变量和局部变量。

成员变量：定义在类里面，方法外面的变量，属于类或类的实例对象的一部分。又分为两种：实例变量和类变量。前者没有static关键字。此处不展开细说。

定义方法：[访问修饰符] [非访问修饰符] 数据类型 变量名 = [初始值];（public final int HOST_HEIGHT = 165;）如果不加访问修饰符则会默认为包内访问权限。

局部变量：定义在方法/构造方法内部/代码块（接下来讲的if/for）的变量。只在定义它的范围内有效。定义时不需要加访问修饰符。

一个方法中，默认局部变量优先级高于成员变量（遵循就近原则），因此如果想要将方法中的参数赋值给成员变量，为了避免重名导致输出空值，要添加this关键字。

```java
public void setGrab(double grabPosition) {  // 前面已经定义过一个同名成员变量
    this.grabPosition = grabPosition;       // 将方法中的参数赋值给成员变量
}
```

虽说当成员变量与局部变量不同名的时候不必加this关键字，但出于代码习惯与人道主义精神，建议全部使用this。

this还可以用于在构造方法中调用同一个类的其他构造方法：

必须写在构造方法的第一条语句;

一个构造方法里只能调用一次, 且不能和super()（之后会提一嘴）同时出现;

- 不能两个构造方法互相调用;

```java
public class Arm {
    private double grabPosition;

    // 无参构造：默认初始位置 0.4
    public Arm() {
        this(0.4);  // 调用下面的有参构造
    }

    // 有参构造：自定义初始位置
    public Arm(double initialPosition) {
        this.grabPosition = initialPosition;
    }

    public void grab() {
        grabPosition = 0.92;
    }

    public void open() {
        grabPosition = 0.4;
    }

    public void show() {
        System.out.println("夹爪 = " + grabPosition);
    }
}
```

new关键字在讲构造方法时已经出现过。new 是实例化、初始化的集成：创建一个对象（arm）、调用Arm类的构造方法，完成初始化，即 grabPosition = 0.4，名字是“社员甲”。

```java
Arm a1 = new Arm("社员甲");   // 声明、实例化、初始化的集成
Arm a2 = new Arm("社员乙");   // 显然，同一类可有多个对象
a1.grab();                   // 这两种调用方式完全不同；前者是调用构造方法进行初始化；这个是调用普通方法
a1.show();
```
