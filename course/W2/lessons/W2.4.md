if 与 for:（同C++，信息课上也会讲Python版本的，所以就不细讲了）

```java
public void check() {
    if (grabPosition > 0.9) {
        System.out.println("夹紧了,小心夹坏");
    } else {
        System.out.println("安全");
    }
}
```

```java
for (int i = 1; i <= 3; i++) {
    Arm a = new Arm("社员" + i);   // 批量生产NPC社员（a即局部变量）
    a.show();
}
```

流程控制中if和for以及while是最常见的，在学习一个switch之后对于FTC与日常JAVA学习已经够用。switch 放在下一节课讲，while跟for一样简单，效果也略有相似，我就不讲了，到时候看到了自然就会了。
